latex-speed-commands already moves, promotes, demotes and narrows sections. So this package covers what it lacks:

- **Refile and goto across the whole book.** `C-c C-w` lists every heading in every file reached from the master file through `\input`, `\include`, `\subfile`, `\import` and `\subimport`, plus a "top level" target for each file. The section becomes the last child of the target, and its headings change level to fit. A `\section` refiled under a `\section` becomes a `\subsection`. `C-u C-c C-w` only jumps to the heading, and `C-c M-w` copies instead of moving.
- **Section in an indirect buffer.** `C-c C-x b` works like `org-tree-to-indirect-buffer` and reuses one buffer.
- **Sparse tree.** `C-c /` hides everything except the matching lines and the headings above them.
- **List items.** You can move an item up or down, indent it into a nested list, outdent it, and cycle the list between itemize, enumerate and description with `C-c -`. Nested lists travel with their item, and the list is reindented afterward.
- **Org's Meta-arrow keys.** On a heading line or in a list item, `M-<up>`, `M-<down>`, `M-<left>`, `M-<right>`, `M-S-<left>` and `M-S-<right>` act on the section or the item. Elsewhere they keep their normal meaning.
- **Speed keys, if you want them.** `latex-structure-speed-commands-setup` adds `W` (refile), `g` (goto), `T` (indirect buffer) and `/` (sparse tree) to your speed keys at headings. It also adds item keys (`n p U D l r -`) at the start of an `\item` line.

The package does not depend on latex-speed-commands. It has its own copy of the section model, using the same defaults.

Things you should know:

- **A bug the tests found that also affects latex-speed-commands.** A section in `main.tex` that comes just before an `\include` line used to take the `\include` line with it when moved. I made `\include` lines a section boundary here. latex-speed-commands still has this bug in its boundary regexp, so its own move and kill commands can carry an `\include` line along.
- **Key clash with Org.** In Org the speed key `w` refiles, but in latex-speed-commands `w` copies the section. That is why refile is on `W` here.
